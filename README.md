# [MSOD-B / Single-Cell RNA Sequencing]

An interactive R Shiny web application built using
[ShinyCell2](https://github.com/the-ouyang-lab/shinycell2) for exploring
single-cell RNA sequencing (scRNA-seq) of MSOD-B cell line at passage
21, 27, and 35. Deployed on **SciLifeLab Serve**.
